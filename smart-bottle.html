Smart Bottle Sorting Machine

An Arduino-based automated sorting prototype designed to identify bottle materials and direct them into separate compartments. The project combines sensor technology, embedded programming and mechanical sorting into a practical recycling solution.

Status In Progress
75%

Project Progress

The project is currently around 75% complete. The core detection and sorting functionality has been successfully implemented while the remaining material detection modules are being developed.

01 — Overview

Turning waste sorting into an automated process.

The Smart Bottle Sorting System was developed as a low-cost automated recycling prototype. The system detects an incoming bottle, identifies its material using sensors and directs it toward the appropriate sorting compartment.

01

The Problem

Manual bottle sorting is time-consuming, requires significant human involvement and can lead to incorrect material segregation.

02

Our Approach

We combined an Arduino Uno with sensors and a motorized sorting mechanism to create a small-scale automated sorting prototype.

03

Our Goal

To develop an affordable and practical system capable of automatically detecting and separating different bottle materials.

02 — System Workflow

From detection to sorting.

The system follows a simple sequence in which the bottle is detected, analysed and directed to its designated compartment.

01

Bottle enters the detection area.

02

IR sensor detects bottle presence.

03

Inductive sensor checks for metal.

04

Arduino processes the sensor data.

05

Sorting mechanism moves to the correct position.

06

Bottle is directed into its compartment.

04 — Hardware

What powers the system.

The prototype combines sensing, control and mechanical components to perform the sorting process.

Arduino Uno R3 Main controller
IR Sensor Bottle presence detection
Inductive Proximity Sensor Metal detection
Capacitive Sensor Non-metal detection
FSR Sensor Weight / material sensing
SG90 Servo Motor Sorting mechanism
28BYJ-48 Stepper Motor Rotating sorting tray
LEDs & Buzzer System feedback

06 — Challenges

What we learned while building it.

Challenge 01

Sensor Calibration

Sensor sensitivity changed depending on the distance between the sensor and bottle. We adjusted the sensor position and detection thresholds through repeated testing.

Challenge 02

Motor Alignment

The sorting mechanism required accurate positioning. Servo angles and movement delays were recalibrated to improve alignment.

Challenge 03

System Integration

Combining multiple sensors created unstable readings during early testing. We solved this by developing and testing each module step-by-step.

07 — Future Development

Where we are going next.

The current prototype establishes the foundation for a complete multi-material sorting system. Our next stage focuses on improving material identification and integrating all modules.

Plastic detection — develop and calibrate the plastic identification module.
Glass detection — improve non-metal material differentiation.
Paper detection — implement a reliable method for paper identification.
Full integration — combine all detection modules into one workflow.
Accuracy improvements — reduce incorrect classifications and improve reliability.
Final testing — perform complete system testing under different conditions.
